## Explore Design Lab

Choose any of the 50 themes using the shared selector. Search projects, filter the collection, save ideas, read notes and add a project for the current session. Switching themes keeps your work. The adjacent **Website Demo** tab shows the same theme on the sample catalog and retains its own search, filters and sorting.

Share a theme with `/?theme=vscode`, or open its catalog with `/?view=website&theme=vscode`. The URL selection takes priority over the saved theme. New visits open All by default, even when a theme selection was saved. A direct `?theme=` link still opens that theme in Design Lab; the previous `/lab/` entry remains available.

## Use with an AI agent

```text
Read SKILL.md in this repository. Add the Command line and Retro themes to my
existing app using its current theme provider and selector. Preserve all existing
themes and business behavior. Verify desktop/mobile and report what you tested.
```

For Codex, copy this repository's contents, excluding `.git`, into `~/.codex/skills/creative-theme-system/`, then invoke `$creative-theme-system`. Other agents can read `SKILL.md` directly and follow the linked references. No connector or account is required for local theme work.

## Run the demo

Requires Node.js 18 or later. No dependencies or build step.

```sh
node scripts/create_demo.mjs ../theme-demo
node scripts/validate_demo.mjs ../theme-demo
node scripts/serve.mjs ../theme-demo --port 4173
```

Open `http://127.0.0.1:4173/?theme=commandline`. Use the dropdown to switch themes. Sample cards open a preview dialog; search, filtering and sample sorting work across selections. Fonts load optionally from Google Fonts with system fallbacks.

The generator refuses non-empty destinations. The preview server binds only to localhost. Publishing is optional and requires the user's authorization; [publishing guidance](references/publishing.md) covers GitHub/Vercel without embedding accounts or tokens.

## Deploy the live gallery on Vercel

The root `vercel.json` publishes `assets/starter/` as the website. It uses the Other framework preset, skips dependency installation and builds, and serves the three-tab explorer at `/`, defaulting to All. The retained catalog is `website.html`; the standalone Lab is `lab/index.html`. Import this GitHub repository into Vercel with the repository root as Root Directory; keep the included settings. No environment variables or backend are required.

The official demo is hosted at [theme.devoralabs.tech](https://theme.devoralabs.tech/). The theme dropdown preserves the shared demo state. Share a selected theme directly, such as [Devora Signal](https://theme.devoralabs.tech/?theme=devora-signal) or [Devora Folio](https://theme.devoralabs.tech/?theme=devora-folio), using `?theme=` with any registered theme ID. The catalog is an English fictional demonstration, with no checkout or real product sales. Standalone signature showcases remain available in the repository; the explorer, retained website catalog and all-theme Lab are published by this configuration.

For a CLI deployment from this repository root:

```sh
npx vercel link
npx vercel git connect https://github.com/devoralabsapp/creative-theme-system-skill.git
npx vercel deploy --prod
```

Use the intended Vercel account/team and existing project when already linked. The local `.vercel/` link is ignored by Git. `.vercelignore` omits skill instructions, documentation and standalone source showcases from CLI uploads; Vercel only serves the configured output folder. The Git connection supports subsequent deployments from the production branch.

## Layout

- `SKILL.md` — agent instructions and routing.
- `references/` — recipes, integration, validation and optional publishing.
- `assets/starter/` — default three-tab explorer, retained website demo, all-theme Lab and original sample assets.

The review page was checked at four widths. The five replacement compositions also passed long-title checks at desktop/320px and actual file/shot selection checks. These checks cover the bundled samples and are not a full accessibility audit.
