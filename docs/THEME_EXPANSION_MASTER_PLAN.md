## Integration sequence

1. Phase 1 introduces a small shared expansion renderer, scoped tokens, material/layout rules, original SVG generation, registry-driven counts and reusable browser verification. Subsequent phases add explicit design definitions and composition adaptations through these primitives.
2. Each identity has its own composition + card grammar + motif + material signature and a practical agent recipe. Preserve all existing business/session behavior.
3. Capture actual Lab thumbnails for All and README; inspect a batch contact sheet and representative phone captures. Run both-view layout/contrast/interaction checks at 320/390/768/1024/1440.
4. Validate, update catalog/progress, commit and push each phase. Follow the existing Git-connected production deployment and verify live content. Do not create replacement projects or duplicate running deployments.
5. Finish with full original/new regression, selector/deep-link/persistence checks, current documentation and a final release commit.

## Deliberate fallbacks

Depth and optical art use bounded original SVG/CSS, front-facing text and native controls. Opaque reading surfaces remain usable without backdrop filters. Reduced motion removes optional transitions. This release does not claim real WebGL, media playback, infinite-canvas editing, gamification, telemetry or third-party integration.

## Implementation result

All seven implementation phases are complete: 51 additions, 101 actual registered themes. The original fifty remain intact. Phase-by-phase QA, commit and production evidence are recorded in [progress](THEME_EXPANSION_PROGRESS.md). Final regression covers both views of the entire collection at all five required widths.
