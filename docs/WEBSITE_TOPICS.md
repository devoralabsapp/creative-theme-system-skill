## Content and artwork

Edit `docs/site-demos/concepts.json`, then run `node scripts/build_site_demos.mjs`. This builds `assets/starter/site-registry.js` and seven SVGs per site under `assets/starter/assets/sites/<theme-id>/`. The illustration motifs are defined in `scripts/lib/site-art.mjs`; unknown motifs fail the build.

Search, category, ordering, selection and saved entries are scoped to each topic for the current page session. Returning to a topic restores its state; refreshing clears it. Design Lab retains its separate project collection.
